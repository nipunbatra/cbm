## s04 | From concepts to predictions: the arithmetic | 0.4 | 0.8
[[Follow the {x:image} all the way to {y:class probabilities}]] Start with an image. The concept predictor estimates the concepts in it. The task head reads those estimates and produces class scores. Softmax converts the scores into class probabilities. The task head can be a single linear layer or a multilayer perceptron, an MLP. We will use one linear layer so that we can see every calculation. || 0.8
[[Three {y:classes} and three {c:concepts}]] Our possible classes are zebra, horse and giraffe. For every image, we predict the same three concepts, in this order: stripes, horse-like shape and long neck. These concept names are fixed before we train the model. || 0.8
[[The {x:concept predictor} turns this image into three {c:estimates}]] The concept predictor, g theta, is a neural network that takes the image as input. For this hand-chosen example, suppose it predicts stripes 0.1, horse-like shape 0.9 and long neck 0.1. These are assumed outputs for this photograph, not measurements from a trained network. Together they form c hat, the predicted concept vector for this image. The hat means predicted. || 0.8
[[The {f:task head} turns predicted {c:concepts} into {y:class scores}]] Now pass that same concept vector to the task head, f phi. It takes the three concept values and returns one score for each class. Its input is the predicted concepts. It does not see the image directly. This is where we could use a linear layer or an MLP. || 0.8
[[The {c:concept values} describe this image; the {f:weights} belong to the layer]] For our example, choose a single linear layer with no bias. Its weight table, W, has a row for each class and a column for each concept. The zebra row is 3, 1, 0. These are weights, not another image's concept values. We normally learn the weights during training and keep them fixed when predicting new images. Here, both the weights and the concept values are hand-chosen to make the arithmetic easy. || 0.8
[[Inside the layer: multiply each {c:concept value} by its {f:weight}, then add]] Let us compute just the zebra score. Stripes contributes 3 times 0.1, which is 0.3. Horse-like shape contributes 1 times 0.9, which is 0.9. Long neck contributes 0 times 0.1, which is 0. Add these contributions to get 1.2. This is one output of the linear layer. || 1.0
[[The same layer produces all three {y:class scores}]] Repeat that calculation with the horse row and the giraffe row. The layer returns zebra 1.2, horse 1.6 and giraffe 0.2. These scores are also called logits. Only now do we write the shorthand: scores equal W times c hat. This is just the linear layer applied to the predicted concept vector. || 0.8
[[Softmax turns the {y:scores} into {y:class probabilities}]] Pass the score vector through softmax. Exponentiate each score and divide by the total. This gives class probabilities that sum to one. Horse has the largest score, 1.6, and the largest probability, about 0.52. The predicted class is horse. || 1.0
[[A person {e:corrects} one predicted {c:concept}]] Now an observer looks at the image and sees stripes. They correct the stripes value from 0.1 to 1. The other concept values stay the same. This edit replaces one entry in the predicted concept vector. || 1.0
[[Pass the {e:corrected concepts} through the same {f:layer}]] Feed the corrected concept vector into the same linear layer. Its weights have not changed. The new scores are zebra 3.9, horse 0.7 and giraffe minus 0.7. The image and the concept predictor are unchanged. We only replace one concept value before running the task head again. || 1.0
[[After softmax, {y:zebra} has the highest probability]] Apply softmax to the new scores. Zebra now has probability about 0.95. The predicted class changes from horse to zebra. || 1.0
[[Why did the {y:zebra score} rise?]] Only the stripes value changed, by 0.9. The zebra weight for stripes is 3. So the zebra score increases by 3 times 0.9, which is 2.7. That takes it from 1.2 to 3.9. The other contributions stay the same. || 1.0
[[The {c:concept vector} is the point where a person can {e:intervene}]] The full path is still image, concept predictor, concept vector, task head, scores and softmax. A person can correct a concept in the middle, then run the same task head again. The answer can change without retraining either network. || 1.0
