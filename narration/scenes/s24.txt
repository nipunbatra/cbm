[[Nothing checks that a {c:concept} is really in the {x:image}]] Label-free models and LaBo share a weakness: nothing checks that a concept is actually visible in the image. || 0.8
[[Naming a {c:concept} is not the same as pointing at it]] The fix rests on a simple intuition. Naming a concept is not the same as pointing at it. So ask a detector to point at each concept in the image, and count only the concepts it can find. || 1.0
[[Three ways a {c:concept} can fail]] There are three ways a concept can fail. Some are not visual, such as a gull's call. Some describe the setting, not the bird. And some score highly on images that do not contain them, such as a black head on a gull whose head is white. || 1.0
[[High accuracy does not prove meaningful {c:concepts}]] Here is why accuracy alone is not enough. Start with a photo and a pretrained image encoder. In this baseline, the concept layer has randomly chosen weights that stay fixed: it was never taught concepts such as yellow bill. Its outputs still depend on the image. Train only the final head using images and their class labels, then test on new images. When the head can use many of these outputs, the paper finds that accuracy can approach that of concept-based models. Useful image information has survived, even though the layer was never trained to detect named concepts. So check whether a high yellow-bill score really corresponds to a yellow bill, as well as checking the predicted class. || 1.0
[[VLG-CBM asks a detector to find each {c:concept}]] Their method, VLG-CBM, grounds the concepts first. It uses an open-vocabulary object detector: a detector that can search for any phrase you give it, not only a fixed list of objects. It looks for each concept in each training image, and draws a box where it finds it. || 0.8
[[A box means 1, no box means 0]] A concept counts as present only where a box was found. For our gull, the bill, head and wingtips each get a one, and the call gets a zero. We call this vector c det: the concept labels from the detector. || 0.8
[[The {c:grounded labels} train the concept layer with a {l:loss}]] These grounded labels train the concept layer: a linear layer that turns the backbone's features into one score per concept. The loss is a binary cross-entropy, as in the original CBM, but no person draws the labels. || 1.0
[[One term of the {l:loss}, worked out]] One term, as in Part 5. The wingtips have a box, so their label is one; if the layer predicts 0.8, the term is minus log 0.8, about 0.22. The call has no box, so its label is zero; a prediction of 0.2 costs the same, minus log of one minus 0.2. || 1.0
[[Count the non-zero {f:weights} in each class's row]] They also report the number of effective concepts, NEC for short. Each row of the head holds one class's weights, one per concept. Count the non-zero weights in each row, here three, two and four, and average over the classes: the NEC is three. || 0.8
[[A {f:head} that uses every {c:concept} explains nothing]] Why does this count matter? A head that puts weight on every concept can fit almost anything. The paper proves that even a random, untrained concept layer can approximate any linear classifier once there are enough concepts. So a dense head can be accurate and still explain nothing. || 1.0
[[A fair comparison: the same number of {c:concepts} per class]] So the fair comparison gives every model the same budget: the same number of concepts per class. Only then does higher accuracy say something about the concepts themselves. || 1.0
[[The same count in symbols]] In symbols, the count for class k is the zero norm of its row of weights: the number of entries that are not zero. The NEC averages that count over the K classes. || 1.0
[[Five {c:concepts} per class can actually be read]] The paper reports accuracy with the NEC held at five. A head like that can actually be read: each class rests on a handful of named concepts. || 1.0
[[What changed compared with {c:label-free} models]] Compared with label-free models, two things change. The concept layer learns from the detector's boxes instead of copying CLIP's scores, and the head is judged at a fixed number of concepts per class. || 1.0
