## Source and Pages branches

The source repository is https://github.com/nipunbatra/cbm. `main` preserves the full lecture source history;
`gh-pages` holds only the built website and a `.nojekyll` marker. GitHub Pages deploys pushes to `gh-pages`.
Audio and rendered film files are excluded from both branches.

For a release, build and inspect the current deck and notes, then generate the PDF or copy the matching,
already verified review PDF to `deck/concept-bottleneck-models.pdf`:

```sh
npm run content
npm run check
npm run deck:build
~/base/bin/python tools/notes_html.py
# For a fresh PDF: npm run deck:pdf
```

Use a clean worktree of `gh-pages` to copy `deck/`, retaining `.nojekyll`. Commit and push that branch only after
checking the PDF and rendered slides. Verify the Pages deployment, live file hashes and course links. The old
`attention/concept-bottlenecks/` HTML addresses redirect to this site while preserving slide and notes anchors.
The old PDF remains available for existing links.
